骑马钉小册子拼版预演

输入成品页数、每帖张数、装订方向与双面翻转方式，系统自动补空白页、按帖拆分页码， 生成每张纸正反面的左右页位；背面依据长边 / 短边翻转执行坐标变换，保证裁切折叠后的阅读顺序。

供应商 每包张数 每包价格（元） 最少包数 最多包数 操作

每包价格按元填写（最多两位小数，如 123.45），提交时精确换算为分（整数）比较，不使用浮点。 供应商名称不可重复；最少包数为 0 表示不设下限。最多录入 8 条报价。

批号 可用张数 允许帖号（留空 = 全部帖通用） 操作

每个批次填写批号、可用张数与允许使用的帖号（逗号分隔，如 1, 3；留空表示通用批、全部帖可用）。 批号不可重复；帖号须在 1 ~ 实际帖数之间。批次可拆给多帖、同帖可跨批次， 系统按「总缺口最小（= 总领用最大）」求分配：每批领用不超过可用张数，且只能分给允许的帖。最多录入 12 个批次。

固定分帖（默认）：每帖页数 = 每帖张数上限 × 4；总页数不足整帖时，自动在末尾补空白页。 勾选「均衡分帖」后仍以每帖张数为上限，先取最少帖数，再把整本所需纸张在各帖间均匀分配（各帖实际张数差不超过 1）， 各帖按自身页数连续编号，空白页只出现在末帖末尾，爬移补偿也按各帖实际层数重算；响应中每帖返回 actualSheetCount，并汇总相对固定分帖节省的空白页数。 勾选「章节优先分帖」并填写递增的章节起始页后，系统在每帖不超过张数上限、每帖纸张数为整数的前提下规划连续页段， 按「章节被拆分次数最少 → 补白页总数最少 → 帖数最少 → 前帖优先装满」确定唯一方案；章节末尾允许插入帖内空白， 后续真实页码保持连续并正确进入下一帖，逐帖展示覆盖章节、真实页范围与补白位置（与均衡分帖互斥）。 纸张厚度与最大补偿量任一为 0（或缺省）时不做爬移补偿；启用后第 i 张（由外向内 i 从 0 起）补偿量 = min(i × 纸张厚度 × 2, 最大补偿量) mm。

适配检查（可选）：同时填写纸张宽高与成品页宽高后，系统按每个正反页位的实际方向计算可用矩形， 检查成品页是否放得下、出血是否落在纸张内、安全边距是否过大，并在逐张预览与清单中标出不合格页位； 四项尺寸全部留空（或为 0）则不检查。出血 / 安全边距缺省为 0。

双面生产标记（可选，需启用适配检查）：勾选后为每张纸生成三类标记——裁切线（四个成品页外角各两段）、 折线标（中线上下两端）与套准十字（左右出血框外侧）；每个标记按固定候选位置顺序尝试， 只有线段完整落在纸内、不穿入两侧出血框内部且不与已放置标记相交才落位（与出血框边界共线或仅端点相接允许， 例如出血为 0 时折线标沿折线与两侧出血框共边仍正常放置），无可用位置则省略；背面标记由正面按长边 / 短边翻转 做同一物理位置的坐标变换，保证正背套准。画布按纸张 mm 等比绘制，省略的标记逐张列出原因，导出 JSON 含每个标记的坐标与原因。

印刷备料（可选）：勾选并填写成品份数、每帖开机损耗张数、过程损耗率（%）与每包张数后，系统按拼版结果各帖实际张数 逐帖计算——净用纸 = 每帖实际张数 × 成品份数；需领纸 = ceil((净用纸 + 开机损耗) / (1 − 过程损耗率))， 各帖分别向上取整后再汇总（禁止先合并各帖再算损耗）；汇总后的需领纸合计按每包张数向上取整得到整包采购量。 过程损耗率按百分数填写（0 ~ 99.999，最多三位小数），提交时按输入的十进制文本精确换算为小数上送（如 0.9% → 0.009，不做浮点除法、不产生 0.009000000000000001 这类尾差），非法或超范围输入会给出可读提示。 结果区逐帖展示净用纸、开机损耗、过程损耗与需领纸，并给出整包采购汇总；导出的拼版清单 JSON 在 materialPrep 段附带相同数据。 不勾选时不进行任何备料计算，响应与之前完全一致。

采购报价组合（可选）：勾选后录入多条本地报价——供应商、每包张数、每包价格（元）、最少 / 最多可购包数。 需求张数默认接入印刷备料汇总后的整包采购张数（备料未启用时请勾选「手工填写需求张数」），也允许手工填写覆盖。 系统在满足需求与各报价边界的全部整数包组合中，按 「总价最低 → 超购张数最少 → 供应商数量最少 → 录入顺序（更早录入优先装满）」确定唯一方案； 价格提交时精确换算为分（整数）比较，杜绝浮点误差。 结果区逐报价展示采购包数 / 张数 / 金额与可购余量；无可行组合时给出具体缺口张数（并按各报价上限列出尽最大可购量）； 导出的拼版清单 JSON 在 purchaseQuotes 段附带相同数据。不勾选时响应与之前完全一致。

双版本共版印刷（可选）：勾选后填写 A 版、B 版成品份数与 B 版相对 A 版改动的真实页码 （支持单页与区间，如 3, 5-8, 12，自动去重并校验页码范围）。系统沿用当前分帖、补白、装订与翻转后的页位 逐张逐面判定：无改动页的面共用一块印版（印次 = A 份数 + B 份数）， 含改动页的面拆成 A、B 两块印版（各按自身份数印刷），同一张纸的正、背面独立判定。 结果区逐面展示帖 / 张 / 面 / 页码 / 印版归属与印次，并汇总印版数（含较全部拆版节省的印版数）与总印次； 导出的拼版清单 JSON 在 dualVersion 段附带相同清单。不勾选时响应与之前完全一致。

库存批次领纸（可选，需先启用印刷备料）：勾选后录入 1～12 个库存批次——批号、可用张数与允许使用的帖号 （留空 = 通用批、全部帖可用）。各帖需求自动取自印刷备料的需领纸 requiredSheets； 批次可拆给多帖、同帖可跨批次，但每批领用不得超过可用张数，且只能分给允许的帖。 系统以最大流求总缺口最小（= 总领用最大）的分配——例如两帖各需 10 张， 一个通用批与一个仅供第 1 帖的批各有 10 张时，专用批自动留给第 1 帖、通用批分给第 2 帖，两帖均无缺口。 结果区逐帖列出各批次领用与缺口、逐批列出领用合计与剩余张数； 导出的拼版清单 JSON 在 stockBatches 段附带相同数据。不勾选时响应与之前完全一致。

试印核验

对照实物纸张录入 1～12 条观察（同一页位不可重复）；服务端用同一输入重算 「左/右装订 × 长/短边翻转」四种设置，逐条比对页码、空白与朝向。 仅唯一零差异组合判定验证通过；并列最优时返回无法判定，不强行推荐， 并自动给出「下一处观察建议」（按最坏情况下剩余候选最少选取，点击「查看建议」可跳到对应纸张高亮页位）。
